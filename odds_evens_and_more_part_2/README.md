## Remainder 3

### Divide by 3 check continued

Last week we talked about the check of adding all the digits together to check if a number could be divided by 3

e.g. `78,435` turns into `7 + 8 + 4 + 3 + 5 = 27` which is divisible by 3.

We showed that 10, 100, 1000 e.t.c were all remainder 1 when divided by 3

So e.g. 4000 has the same <sub>R3</sub> as 400 and as 40 and as 4

and you can always separate any number out into an addition of numbers like this
e.g.

```
5673
=
5000
+600
+ 70
+  3
```

And you can then use the rule above to remove all the zeros

```
5000  same   5
+600  R3    +6
+ 70  as    +7
+  3        +3
```

So we have the rule of 3s!

Some of you were surprised by me crossing out numbers as I checked this:
e.g. turning:
`69,435`
into
`00,405`

> Why is it OK to do this when checking for divide by 3s?

```
A x A x A
```

| | A x A x A |
| --- | --- |
