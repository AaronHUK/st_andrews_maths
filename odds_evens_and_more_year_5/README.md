# Odd and Even

## Remainder 3

### A surprising result

For any number A, the sum
```
(A x A x A) - A
```

also written as A<sup>3</sup> - A

is *always* divisible by 3.

<details>
  <summary>Examples</summary>

| A | A<sup>3</sup> - A | divided by 3 is |
| --- | --- | --- |
| 1 | 1 - 1 = 0 | 0 |
| 2 | 8 - 2 = 6 | 2 |
| 3 | 27 - 3 = 24 | 8 |
| 4 | 64 - 4 = 60 | 20 |
| 5 | 125 - 5 = 120 | 40 |
| 6 | 216 - 6 = 210 | 70 |
| 7 | 343 - 7 = 336 | 112 |

</details>

## Working out why

Let's look at the addition, subtraction and multiplication tables for remainder 3:

| + | 0<sub>r3</sub> | 1<sub>r3</sub> | 2<sub>r3</sub> |
| --- | --- | --- | --- |
| 0<sub>r3</sub> |   |   |   |
| 1<sub>r3</sub> |   |   |   |
| 2<sub>r3</sub> |   |   |   |

| - | 0<sub>r3</sub> | 1<sub>r3</sub> | 2<sub>r3</sub> |
| --- | --- | --- | --- |
| 0<sub>r3</sub> |   |   |   |
| 1<sub>r3</sub> |   |   |   |
| 2<sub>r3</sub> |   |   |   |

| 1<sub>r3</sub> |   |   |   |
