# Odd and Even

## Remainder 3

### Divide by 3 check continued

### A surprising result

For any number A, the sum
```
(A x A x A) - A
```

also written as A<sup>3</sup> - A

is *always* divisible by 3.

<details>
  <summary>Examples</summary>

| A | A<sup>3</sup> - A | divided by 3 is |
| --- | --- | --- |
| 1 | 0 | 0 |
| 2 | 6 | 2 |
| 3 | 24 | 8 |
| 4 | 60 | 20 |
| 5 | 120 | 40 |
| 6 | 210 | 70 |
| 7 | 336 | 112 |

</details>
